# BatchCounter Roadmap

## Phase 1 – Basic Demo
- Increment counter on each `Cycle_Complete`.
- Provide simple integer output `Batch_Count`.

## Phase 2 – Reset & Control
- Add operator reset functionality.
- Provide flag for batch logging.

## Phase 3 – Advanced Features
- Timestamp each batch completion.
- Store batch history in array or external database.
- Provide batch rate (batches per hour/day).

## Phase 4 – Integration
- Connect to SCADA/HMI for visualization.
- Export batch logs for compliance and reporting.
- Integrate with CycleManager for multi-tank batch tracking.
